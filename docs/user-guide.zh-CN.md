# AI People 操作说明

> 适用版本：v0.3.0（个人版免登录）。阅读对象：在自有 Windows 电脑上使用本软件运营抖音、小红书、微博账号的用户。

## 1. 工作模式：一切发生在电脑上

**不需要连接手机，不需要在手机上安装任何东西。** 系统由三部分组成，全部运行在你的 Windows 电脑：

| 组成 | 是什么 | 在哪运行 |
|---|---|---|
| 工作台 | 你操作的界面（生成内容、审核、排程、看结果） | 桌面应用 `AIPeople.exe` |
| 后台服务 | 账号管理、内容生成、定时调度、状态记录 | 同一台电脑（`pnpm dev`） |
| 执行器 | 到点后真正执行「发布」动作的程序 | 同一台电脑，随 `pnpm dev` 启动 |

**手机的角色只有两个**：

1. 登录平台偶尔需要手机收验证码/扫码（这是平台账号本身的登录流程，与本软件无关）；
2. 发布完成后，你在手机 App 里看到内容——内容是真实发到平台的，手机只是「查看结果」。

**电脑必须开机在线**：定时发布由本机执行器到点执行，电脑关机/断网任务会等待或标记错过（工作台会如实显示）。抖音官方 API 通道例外（后台 Worker 在电脑不在线时也能执行，但当前版本后台也在本机）。

## 2. 账号怎么「连接」：不是装 App，是给授权

工作台的「账号中心 → 连接账号」里，每个平台有两种通道：

### 2.1 模拟器通道（默认，立即可用）

- 选择平台后通道选「模拟器」，起个名字就完成。
- **不连接真实平台**，用于熟悉流程：生成 → 审核 → 排程 → 到点自动「发布」→ 状态流转全程真实，只是发到内置模拟器。
- 想先练手就用这个，随便玩，不影响任何真实账号。

### 2.2 小红书真实通道（redbook 实验适配器）

原理：软件用你提供的**浏览器登录会话**调用小红书网页接口发布，请求从你的电脑发出。

操作步骤：

1. 在电脑浏览器登录 `xiaohongshu.com`（可能需要手机收验证码，一次性）；
2. 按 F12 打开开发者工具 → Application（应用）→ Cookies → `https://www.xiaohongshu.com`；
3. 找到并复制 `a1` 和 `web_session` 两个值；
4. 工作台「账号中心 → 连接账号」：平台选小红书、通道选「redbook 实验适配器」、粘贴两个值、保存；
5. 软件会自动校验会话并读取你的账号 UID 绑定。

**须知**：

- Cookie 是你的登录凭据，软件加密保存、只用于发布，不进日志和 AI 上下文；
- 这是**非官方接口**，存在会话失效、验证码、账号风控风险——平台弹出验证时任务转「需人工处理」，需要你回浏览器真人完成验证，软件不做任何绕过；
- 首次使用建议先发一篇测试内容观察平台反应。

### 2.3 微博真实通道（官方 CLI）

原理：调用微博**官方提供的命令行工具**（weibo-cli），经 OAuth 授权后发布，是最正规的方式。

操作步骤（一次性环境准备 + 连接）：

1. 在电脑上安装官方 CLI 并完成开发者认证（按微博开放平台 open.weibo.com 的指引，认证可能需要微博 App 扫脸，一次性）；开通体验服务或积分包；
2. 完成浏览器 OAuth 登录授权；
3. 运行 `weibo doctor` 记下输出的账号 UID；
4. 工作台「账号中心 → 连接账号」：平台选微博、通道选「微博官方 CLI」、填入 UID、保存。

**须知**：AI 生成内容发布时软件自动声明 AI 属性（平台会加标识，这是合规要求，不可去除）；写入接口有官方额度限制。

### 2.4 抖音真实通道（官方 API，待开通）

需要先在抖音开放平台注册开发者应用并申请 `video.create` 权限（审批制），获批后配置应用密钥、完成账号 OAuth 才能使用。**当前版本此通道为骨架，等待应用审批后启用**——在此之前抖音请用模拟器通道体验流程。

## 3. 日常使用流程

1. **启动**（电脑重启后）：
   ```bash
   cd G:\pjs\aipeople
   pnpm release     # 或 pnpm db:up && pnpm dev（日常开发调试）
   ```
2. 打开「AI People 运营工作台」（桌面快捷方式或 `win-unpacked\AIPeople.exe`）——免登录，自动连接后台；
3. **资料与素材**：录入真实产品资料、案例、品牌说明（这是 AI 创作的事实来源，AI 只依据这些资料写内容，不编造）；
4. **内容工作台**：输入运营目标 → 勾选账号 → 生成草稿 → 核对正文、话题、事实引用、AI 声明 → 「送审」→「批准」（批准绑定内容版本，24 小时有效）；
5. 选「单次发布」设个时间，或「周期计划」选每周几几点 → 创建排程；
6. 到点自动执行：状态从 已排程 → 执行中 → 已提交 → 平台审核中 → **已发布**，「结果与数据」页可看回执、链接和数据；
7. 出问题看**异常处理**页：验证码、会话失效、结果未确认都有明确入口和处理指引。

**模型配置**（「助手与模型」页）：默认用内置 Mock（不花钱、按资料模板生成，适合体验）。接真实模型：添加 OpenAI 兼容供应商，填 base URL + API Key + 模型名（智谱 GLM / DeepSeek / 通义 / Kimi 等都支持），点「测试」验证，生成质量会明显提升。

## 4. 安全与边界（务必了解）

- **验证码不绕过**：平台要求验证时任务暂停转人工，由你真人完成验证；软件不做自动打码、换 IP、模拟人工节奏等任何绕过。
- **AI 标识合规**：AI 生成的内容按平台要求声明，不能移除；商业合作内容需单独标注。
- **凭据安全**：所有密钥/Cookie 加密存储，不进日志、不进 AI 上下文；后台 API 是无登录的个人模式，**只在本机使用，不要把 8787 端口暴露到公网**。
- **不承诺账号安全**：非官方通道（redbook）存在平台治理风险，软件会把拦截如实转人工；官方通道（微博 CLI/抖音 API）是平台许可的方式。
- **内容责任**：AI 只依据你提供的资料创作，发布前请人工核对事实；被平台拒绝的内容修改后重新审核，不要反复换词冲审核。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 打开工作台显示「无法连接后台服务」 | 后台没启动：`pnpm db:up` 然后 `pnpm dev`；或在页面里改后台地址后重试 |
| 登录页不存在？ | 个人版免登录，启动即用；若提示连接失败按上一条处理 |
| 任务一直「等待执行设备」 | 执行器没在线：确认 `pnpm dev`（含 runner）在跑，或总览页看设备状态 |
| 任务标记「需人工处理」 | 去「异常处理」页看原因：验证码回浏览器真人完成；会话失效重新连接账号 |
| 小红书任务频繁验证码 | 平台风控收紧，暂停使用该账号一段时间；换官方渠道或降低发布频率 |
| 定时任务「已错过窗口」 | 电脑当时关机/断网；在任务详情里重新排期 |
| 生成的内容不理想 | 先充实「资料与素材」（内容质量取决于资料质量）；或在「助手与模型」接真实大模型 |

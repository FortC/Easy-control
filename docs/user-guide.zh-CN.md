# Windows 用户指南

## 安装

从项目 GitHub Releases 下载当前版本安装包，按向导选择每用户安装目录。安装包没有代码签名证书，Windows 首次运行可能提示未知发布者。第一次打开会在本机初始化数据库和默认个人工作空间，稍等数秒即可进入总览。安装过程中无 Docker、数据库服务或 Node.js 配置。

关闭主窗口会将软件收进系统托盘。右键托盘可重新打开或退出。正常排程期间请保持软件运行、电脑联网且未休眠。退出后未完成的任务会标记为「待核实」，避免错误重发。

## 接入平台 CLI

打开「CLI 接入中心」，查看平台、上游仓库、开源许可、固定版本和功能范围。选择内置工具后点击安装，应用使用自带 npm/Node 安装到本机数据目录；也可以选择可信的本机 EXE/JavaScript 命令行入口，按上游说明添加动作模板。

CLI 安装需要联网。安装过程不执行 npm 包生命周期脚本；安装后用「使用帮助」或只读查询确认该 CLI 版本能正常运行。工具列表的开源许可证和平台官方服务费用是两件事；用户自行导入的工具不一定免费。

小红书在第一版只有内容助手与真人交付工作区，不添加 CLI 账号、不读取或保存 Cookie/浏览器会话，也不自动登录、模拟键鼠发布或自动评论、私信、群聊。请在内容工作台生成并编辑笔记，完成软件内审核后复制文案/话题、打开小红书，再由你本人检查素材、声明和可见范围并在平台内完成发布。审批只用于内容审核归档，不会触发平台动作。旧版本保存的小红书 CLI 会话会在升级时清除，未开始的旧排程会取消。

微博官方 CLI 支持从指令中心运行设备码授权、账号信息、连接诊断和授权命令发现。授权跳转至微博官方页面；命令范围和服务成本以官方帐号提示为准。知乎、抖音可从 OpenCLI 发现本机可用命令或导入经核验的官方/第三方 CLI。应用不会自动生成未验证的接入能力。

「账号中心」按 CLI 工具维护多个账号、昵称、UID 与独立配置。保存环境变量后，软件在本机加密保存并隐藏回显。变更了 CLI 会话后重新运行只读身份检查。UID 不匹配时外发动作会被阻止。账号设置异常时暂停此账号，先在平台正常恢复会话，再核验 UID。

## 模型、指令和排程

在「助手与模型」配置 API 兼容供应商地址、模型和 API Key。连接测试通过后，模型可基于当前工具动作列表生成参数建议，也能总结执行输出。模型不会读取 CLI 凭据或直接启动进程。未配置真实模型时，可在指令中心手动挑选工具和动作。

允许 CLI 执行写操作的平台需选择具备已核实 UID 的账号、填写内容并勾选外发确认。先运行只读命令确认权限和登录状态，再准备需要发布的具体内容。小红书始终由真人在平台内交付，审批或定时设置都不会启用小红书自动写入。执行状态区分已完成、失败、需人工、待核实与错过时间。已完成表示命令返回成功；请按工具结果到平台核实公开状态、链接和可见范围。验证码或登录失效会暂停账号并转人工；不要反复尝试或自动重试。

执行时间留空表示立即执行。设置时间则在本机排队，并受软件运行、联网和系统休眠影响；30 分钟后才恢复运行的任务会过期，不会补发。排程可在任务列表中取消。结果面板可导出 JSON 或要求模型总结。

## 本地循环讲解

进入「直播工作台」，选择 MP4 或 WebM，设置横屏或竖屏、Windows 声音、语速，写讲稿并试听。分段文本按顺序朗读；打开「循环念稿」后结束会回到第一段。点击「开始讲解」会打开独立输出窗口，视频循环播放并显示字幕。AI 辅助讲解状态保持可见。

用 OBS 或平台直播伴侣进行窗口捕获，并在其软件中单独配置应用音频捕获。Easy Control 当前只提供可捕获的窗口画面与声音；它不会登录直播平台、启动直播、处理礼物互动或上传 RTMP。上线前按照平台要求标识 AI 生成内容/AI 直播并检查音乐、图片、视频的版权。

## 数据备份与支持

进入「关于与帮助 → 打开数据目录」备份整个应用数据目录。将软件迁移到另一 Windows 帐户后，DPAPI 保护的账号/模型秘密可能需要重新填写；不要把该目录同步到未授权的共享位置。任务记录和直播场景可随目录备份。

遇到问题先在 CLI 接入中心运行帮助或连接诊断，核对具体账号状态及动作模板，再查看结果页的标准输出、错误输出与异常原因。提交问题前清除错误信息中的个人内容和授权信息。联系 clb：lamthebest@foxmail.com；问题反馈页：[GitHub Issues](https://github.com/FortC/Easy-control/issues)。

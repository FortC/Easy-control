# 平台与工具接入矩阵

工具版本和仓库元数据在软件 CLI 接入中心内一并展示。固定版本用于复现构建；执行前建议在上游检查更新、许可和平台兼容性。Star 数是调研当时的快照，不能代表官方背书、持续维护保证或实际账号可用性。

| 平台 | 首选接入 | 当前软件入口 | 当前边界 |
|---|---|---|---|
| 小红书 | 内容工作台 + 真人交付 | AI 辅助起草、编辑、内部审核、复制/导出；`redbook` 仅显示元数据并允许 `--help` | 不创建小红书 CLI 账号，不读取/保存 Cookie 或浏览器会话，不自动登录、模拟键鼠发布、评论、私信或群聊；升级时清理旧会话并取消未开始的旧排程 |
| 微博 | 微博官方 CLI | 安装 `@weibo-ai/weibo-cli@0.9.8`；设备码授权、我是谁、doctor、已授权命令发现 | 命令权限与平台收费以官方账户显示为准；实际发布权限由官方 OAuth 决定 |
| 多平台（含知乎/抖音） | `jackwener/OpenCLI` 社区工具 | 安装 `@jackwener/opencli@2.0.2`；帮助、平台发现、知乎热榜模板 | 上游按命令接入所需平台；登录、账号隔离与写入参数需逐个 CLI 子命令确认，目录不会据此虚称所有平台皆可发帖 |
| 知乎、抖音或其他 | 用户导入本机官方/第三方 CLI | 选择 EXE 或 JS/CJS/MJS；按其文档声明动作模板 | 仅按 Windows 可执行入口运行；身份动作必须配置成固定只读命令；由用户核验来源、功能和许可证 |

平台官方接口通常要求开发者资质、应用审核、OAuth 授权、用户同意范围和平台特定权限。应用暂不将非公开 API 伪装为官方 API，也不实现验证码规避、指纹伪装、代理池或并发批量外发。第三方自动化违反平台规则时，应停止执行，转由账号所有者处理。

小红书工作区不是平台账号连接。内容审核通过后，用户可以复制标题、正文与话题并打开平台网站，检查素材和声明后由本人完成发布；软件不会操作平台账号页面。社区 CLI `lucasygu/redbook` 可用于查看项目资料，但其账号动作不会进入软件执行器。

微博 CLI 的设备码登录和命令发现基于微博 CLI 官方 Quickstart；安装工具是免费的，并不保证官方接口调用无服务费。
